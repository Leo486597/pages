# 针灸 · 失眠（不寐）调理图解

在线：https://leo486597.github.io/pages/zhenjiu-bumei-shimian/

以《针灸学》（十四五）「不寐」一节为主线，把主方 6 穴、5 个证型的配穴，以及艾灸、耳穴、头针、刮痧、梅花针、涌泉等其他疗法，逐个落到定位、取穴步骤、针刺量、在家做法上，每穴配课件定位图和取穴视频截帧。

原方（教材 p222–223）：

> 治法：调和阴阳，安神利眠。以督脉、手少阴及足太阴经穴、八脉交会穴为主。
> 主穴：百会　神门　三阴交　照海　申脉　安眠
> 操作：毫针刺，泻申脉，补照海，其他按虚补实泻操作。

## 这页真正解决的几件事

1. **照海、申脉为什么一补一泻**：卫气行于阳则阳跷盛（目张不欲睡），行于阴则阴跷盛（目闭欲睡）。失眠是阳跷偏盛，所以泻申脉（阳跷）、补照海（阴跷）；嗜睡反之。
2. **两本教材分型不一样**：《中医内科学》有「痰热扰心」，《针灸学》换成「脾胃不和」；页内并列，并给出内科学方剂对照。
3. **艾灸不是谁都能用**：教材「不寐」没列灸法。页内按「灸法温补」推出：心脾两虚、心胆气虚适合；肝火扰心、心肾不交（手脚心热、舌红）不灸，改用搓涌泉、按太溪。
4. **梅花针叩哪里**：教材只写「项至腰沿督脉、膀胱经第 1 侧线」和「叩打头部诸经」；中国针灸学会官网的神经衰弱方案补上了颈椎 1–7、胸椎 5–12 两侧、额部三行、头部网状、神门／足三里／三阴交，以及轻中度手法和疗程。
