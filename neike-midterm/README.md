# 内科期中 · 总论→噎膈

中医内科学 (十四五) 期中备考站, 手机优先, 纯静态 (无网络请求, 无运行时 AI)。

- 顺序: 0 总论 → 1–7 七类 (同一病机的病放一类, 一个病可在多类)。每类先读开篇课 (跨病的共同病机 + 易混表)
- 每章按考点组织: 每个考点 = 2 分钟讲解 (出自胡秋荣讲义 + 十四五题库解析, 标来源) + 题库里考这个点的全部题
- 题库: 十四五习题集选择题, 范围内 1538 题 (A1/A2/A3/B/多选), 每题答案 + 解析
- 练习: 推荐 10 题 (该复习 → 薄弱考点 → 没碰过的考点), 练某个考点, 错题本, 模拟 50 题; 间隔复习 1/3/7 天
- 显示: 每章进度, 预计掌握 (按考点加权的答对率估计), 学习时长; 进度存在浏览器 localStorage, 可复制备份
