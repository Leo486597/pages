# AI 芯片与中国 · 出口管制全景 / AI Chips & China

美国对华 AI 芯片出口管制的研究型全景站:规则、逐芯片清单、中美时间线、深度阅读、读者问答、合规路径、司法辖区、执法案例、市场与术语表。中英双语,每条事实带日期的出处。

**研究资料,不构成法律意见。** 任何交易请咨询出口管制律师。法规状态截至 2026 年 10 月 31 日。

## 页面

**全景与工具**

- `index.html` — 全景:两道闸门、芯片速览、关键事实、合法路径、市场、入口
- `chips.html` — 芯片查询:每颗芯片 → 美国闸门 + 北京闸门 → 为什么、规格、出处
- `timeline.html` — 规则时间线:中美两条平行线,2022 → 今天及未来日期

**深度阅读**

- `read.html` — 七章读懂的目录
- `ch1.html` … `ch7.html` — 七章正文:安全问题 → 规则演进 → 第二道关 → 两条线 → 供需 → 被起诉的人 → 合规路径

**问答**

- `qa.html` — 179 条读者提问合并为 123 行,分 10 节(A–J),每问三层作答

**参考**

- `routes.html` — 合规路径 A–G:逐条列出条件与可能关闭它的因素
- `jurisdictions.html` — 司法辖区:中国大陆、香港、新加坡、阿联酋
- `cases.html` — 执法案例:谁被起诉、以何罪名、结果如何(尚无一例判刑)
- `market.html` — 市场:买家、合法供给、国产芯片、缺口
- `glossary.html` — 术语表:37 条法律与技术术语,中英对照

阅读分三层:概览 → 细节(点开)→ 法条与出处(再点)。估算/传闻/未确认/未判之处均打标。
