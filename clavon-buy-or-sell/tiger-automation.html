能不能全自动？——老虎证券模拟盘实测（2026-08-17）

本页回答两个问题：策略卡 v2 能不能在老虎证券（Tiger Brokers SG）一个账户里全自动执行；以及在老虎模拟盘上真的跑一遍会发生什么。结论、证据、每一张单的成交都在下面；这一页由 strategy/report.py 从模拟盘的订单记录生成，重跑即更新。策略本身、为什么是 60/40、入场规则的推导，见 换房建议书 与 策略卡 v2。

0. 结论

问题答案
原方案（VWRA / AGGU / IGLN 伦交所 UCITS + ES3 / CLR + SSB/T-bill + 高息户）在老虎能全自动吗不能。 老虎没有伦交所通道，占组合 70% 的三只 UCITS ETF 买不到（合约壳能下单、永远不成交）；SSB / T-bill / 高息户（15%）不是券商产品；只有 ES3 / CLR（15%）能直接自动
客户要「一个账户管全部」怎么办换成老虎买得到的等价篮子：VT（全球股）/ BNDW（全球债，美元对冲）/ IAU（黄金）/ A35.SI（新加坡政府债 ETF）+ ES3.SI / CLR.SI 不变 + 5% 现金留在账户新元余额 → 100% 在一个老虎账户里，95% 由脚本下单，5% 是本来就该留的现金
代价美股注册 ETF 的股息预扣税 30%（爱尔兰 UCITS 15%）+ 美国遗产税敞口（美国注册资产 > US$6 万部分 40%）；SSB → A35 多了利率波动（久期约 7 年）。税的年化拖累估算 ≈ 0.3–0.5%（⚠️ 估算：VT 股息率 ~1.9% × 15 个百分点 × 45% ≈ 0.13%；BNDW ~4% × 30% × 20% ≈ 0.24%，部分利息收入可免预扣未计入），建议书 里已经把它算作「换工具不换策略」的价签
模拟盘跑通了吗跑通了。 第 1 个月的全部动作（安全层一次性 + 黄金 1/6 + 股票层 1/6 + 定投）从「算清单 → 换汇 → 逐张预览 → 下单 → 成交 → 记账」走完；成交明细在 §3。美股腿在美股开盘（新加坡 21:30）后成交，页面在那之后重跑一次会补上
以后有客户用 IBKR 呢券商层已经抽成接口（strategy/brokers/base.py），老虎是第一个实现（brokers/tiger.py），IBKR 留了骨架与要点（brokers/ibkr.py）；IBKR 有伦交所通道，原方案的工具在 IBKR 可以直接自动，不必换篮子

4. 每月怎么跑（老虎版流水线）

PY=/Users/leo/Documents/finantial-analysi/auto-buy-O39/.venv/bin/python   # 装了 tigeropen 的解释器
python3 strategy/agent.py --init 2026-09                                  # 起投月（一次）
$PY strategy/execute.py --broker tiger --account paper --check            # 连通、合约、价格、现金：不下单
$PY strategy/execute.py --broker tiger --account paper --dry-run          # 到 preview 为止
$PY strategy/execute.py --broker tiger --account paper --run --book       # 下单 + 按真实成交记账（模拟盘）
CLAVON_LIVE_OK=yes $PY strategy/execute.py --broker tiger --account live --run --book   # 实盘：多一道闸门
  • 一个月跑一次就够，但每天跑也安全：每张单带 tag clavon-tiger-<篮子>-<资产>-<年月>，重跑先读自己的 tag，只补差额；成交完就「本月已到位，跳过」。
  • 顺序：算清单 → 券商最新价 → 各币种缺口 → 换汇 → 每张单先 preview（券商给出佣金 / 拒绝理由）→ 限价 DAY 下单 → 等成交 → 落盘 JSON → --book 把真实份数与新元成本记进 state.json。
  • 不做的事：不下市价单（老虎盘外拒绝）；卖出永不超过持仓；实盘 --run 需要环境变量 CLAVON_LIVE_OK=yes。
  • 调度：与 strategy.md §4.3 相同的 cron / launchd，把命令换成上面的 execute.py；美股腿在新加坡晚上成交，所以选每月 3 号 09:05 跑一次、4 号再跑一次补美股腿即可。
  • 仍是人工的：往老虎账户存新元；SRS / CPF 的年度动作（不在这条流水线里）。

5. 历史回测 vs 模拟盘

模拟盘只能向前：它按今天的价格成交，不能回放 2004–2026。所以「回测」仍是 按起点看回溯（2004–2026 真实数据） 与 进场规则实验室；模拟盘证明的是执行链——每一腿买得到、换汇通、幂等、记账对。两者合起来才是「这套规则能自动跑」。

6. 局限与下一步

  • 老虎这个 tiger_id 没有实时报价，参考价是当日 K 线（盘中即最新价）；限价 +0.3% / +0.5% 是为了当天成交，代价是最多多付这么多。
  • 老虎对 VWRA 等伦交所代码给出「能下单」的假象（合约壳）：任何新工具都必须先在模拟盘下一张小单看它成不成交，别信 preview。
  • 税的拖累是估算（§0），未按客户实际税务身份核。
  • 下一步：① 客户确认「老虎篮子」的三只美股 ETF 与 A35 替代；② 实盘账户存入新元；③ 首月在实盘 --dry-run 看单再 --run；④ IBKR 适配（有伦交所，可回到原工具）。
